# WEBPOS 使用說明（獨立專案 v0.6.2，適用零售業）

> 適用對象：文具行、雜貨店、零售門市等免建商品檔、快速收銀場景。

## 啟動

1. 雙擊 `run.bat`（自動開瀏覽器到 `http://127.0.0.1:5000/`）。
2. 或手動：`pip install flask` → `python app.py`。
3. 首次開機：商店無預設值，會自動彈出「商店設定」，填完才能結帳。

## 日常操作（實體鍵盤）

- 品名（預設文具）→ Tab → 數量（預設1）→ Tab → 單價 → `Enter` 加入清單。
- 數量 1–99，單價 1–5000，小計＝數量×單價。
- `↑↓` 選列、`M` 修改（品名/數量/單價）、`Del` 刪除（二次確認）。
- 明細表頭：項次｜品名｜數量｜單價｜總金額｜操作；超過一屏清單內捲軸捲動。
- `F9` 結帳：對帳預覽 → 輸收現（預設＝合計，Enter 確認）→ 自動列印交易明細 → 大字找零 → 下一筆（發票自動跳號）。
- `F5` 401 月報（逐日起訖＋總額/銷售額/稅額＋期別，可列印；內有「今日日結」可作廢/重印）。
- 抬頭：左為公司名（讀商店設定）＋版號；右為「下一張：ZZnnnnnnnn」（要開的號）＋商店設定／字軌設定鈕。
- `Esc` 清空輸入 / 整單清除。

## 商店設定（右上）

- 公司名稱／統編（8碼）／地址／電話，四格全必填，無預設值。
- 公司名稱會出現在主畫面標頭與交易明細第一行。

## 字軌設定（右上）

- 三格：前二碼英文／開始號（8碼）／停止號（8碼），例 AB12300001–AB12300299。
- 只認範圍內號碼，超 range 擋結帳（提示換新發票本）；剩 20 張黃底提醒，用罄擋結帳。
- 同本改停止號沿用進度；換新本從開始號。

## 交易明細列印格式

```
公司名稱
統編號碼
地址
電話
YYYY-MM-DD HH:MM
1. 文具 $100*2 200T
合計／應收／收現／找零
```

- 不印發票號（實體二聯已有）、不印稅額；確認結帳自動列印。

## 鍵盤卡

- 開 `static/keyboard-card.html` 列印 A5，貼螢幕旁。

## 驗收

- `python -m pytest tests -q` 全過＋`GET /health` 正常。
- 開單→F9→列印→F5 月報有記錄；跳號連續無斷號。
